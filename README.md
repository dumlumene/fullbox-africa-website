# Fullbox Africa Website

A responsive, high-conversion corporate website prototype for Fullbox Africa.

## Included
- Responsive homepage
- Fullbox positioning and messaging
- Solutions / problem section
- Fulfillment architecture
- 3-step workflow
- West Africa network visual
- Interactive indicative pricing calculator
- Developer/API section
- Pilot lead form
- Mobile navigation
- SEO metadata

## Before production
1. Connect the pilot form to HubSpot/Apollo.
2. Replace demo calculator assumptions with approved commercial pricing.
3. Replace target/indicative service claims with verified operational SLAs.
4. Add real API documentation and merchant portal links.
5. Add real analytics, cookie consent and GDPR tooling where required.
6. Connect a domain and deploy on Webflow, Vercel, Netlify or another production host.
